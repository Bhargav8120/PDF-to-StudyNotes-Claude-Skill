# Note style guide

- Use descriptive headings and a consistent hierarchy.
- Prefer complete explanations over disconnected bullet fragments.
- Use bullets for lists, steps, properties, and concise takeaways.
- Use tables for direct comparisons; avoid very wide tables.
- Put equations on separate lines and define symbols immediately below.
- Use fenced code blocks with language labels for code.
- Add source page references near the relevant explanation.
- Mark added illustrative examples explicitly.
- Mark uncertain extraction as **Needs verification**.
- Keep the chapter recap concise and explanatory, not exam-oriented.
